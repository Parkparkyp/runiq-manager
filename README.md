# 루닉필름 매니저
웨딩 촬영 예약/입금/캘린더 관리 PWA (서버·DB 없음, 데이터는 기기 localStorage 저장)

## 폴더 구성
index.html · manifest.json · sw.js · icons/ (이 파일들을 같은 폴더에 두세요)

## GitHub Pages 배포
1. 저장소에 위 파일 전부 업로드 → Settings → Pages → Branch: main / (root)
2. 발급된 https 주소를 폰 크롬에서 열기 → ⋮ → "앱 설치" 또는 "홈 화면에 추가"

## 주의
- 데이터는 기기·브라우저별로 따로 저장됩니다. 설정 탭의 JSON 백업을 주기적으로 받으세요.
- file:// 로 열면 서비스워커(오프라인)가 동작하지 않습니다. 꼭 Pages(https)로 여세요.

## 카톡 자동인식 지원 형식
날짜: `27.5.21` `5.21 27년` `27년 5월 21일` `2027-05-21` `5/21` `내년 5월 21일` (요일 `(토)`을 같이 쓰면 연도·요일 불일치를 자동 점검)
시간: `오후 1시 반` `1시30분` `13:30` `열두시` `1pm` (오전/오후가 없으면 1~8시는 오후로 추정, 노란 경고 표시)
성함: `유가비입니다` `김하늘/박서준` `신랑 ○○ 신부 ○○`
포트폴리오 동의/미동의, 연락처, 결제방식, 예약상품도 문장 속에서 찾아냅니다.

## v3 주요 기능
- 탭: 캘린더 / 예약문의(연·월 묶음) / 현황(그래프·금액·납품·짝꿍코드) / 설정(금액·할인·멘트·휴무일·백업)
- 상태: 문의접수 → 입금전 → 계약금완료 → 촬영완료 (취소). 기존 '입금후'는 자동으로 '계약금완료'로 바뀝니다.
- 포트폴리오 동의 시 설정한 금액만큼 자동 할인, 짝꿍코드는 계약금완료 시 자동 발급 (사용 횟수·할인액은 설정에서)
- 납품 체크/기한 알림, 현금영수증 체크, 지도 버튼, 휴무일 지정, 백업 알림, 문의 경로 통계
