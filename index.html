☁️ 구글 시트 클라우드 백업

내 구글 시트에 백업하고, 자동 동기화를 켜면 폰·컴퓨터의 예약이 서로 합쳐져요.

📖 처음 연결하는 방법
  1. 구글 드라이브에서 새 구글 시트를 만들어요 (이름 예: 루닉필름 데이터)
  2. 메뉴 확장 프로그램 → Apps Script 를 열어요
  3. 기본 코드를 지우고 apps-script/Code.gs 내용을 붙여넣어요
  4. 맨 위 SECRET 값을 나만 아는 긴 문자열로 바꾸고 저장해요
  5. 배포 → 새 배포 → 웹 앱 선택, 실행: 나, 액세스: 모든 사용자 → 배포 (권한 승인 필요)
  6. 나온 웹 앱 URL 과 SECRET 을 위 칸에 붙여넣고 저장 · 연결 테스트
📝 전자 계약서 (링크로 받기)

예약 카드의 [📋 입금전 안내] 또는 [📝 계약서 링크 복사]를 누르면 고객 전용 링크가 만들어져요 (입금전 멘트에는 자동으로 들어가요). 고객이 링크에서 계약서를 읽고 서명하면 연락처·포트폴리오 동의가 앱에 자동으로 들어와요. 서명 후 7일 동안만 고객이 사본을 다시 열 수 있고(연락처는 가려서 보여요), 고객은 PDF를 직접 저장해요. ☁️ 클라우드 백업 연결이 먼저 필요해요.

작성 방법: 항목은 한 줄 ===== 로 나눠요. 각 항목의 첫 줄이 제목이고, 마지막 줄을 ☑ 동의합니다. 처럼 쓰면 그 문구가 고객 체크칸 이름이 돼요. 항목 안에 [[포트폴리오선택]] 을 쓰면 그 자리에 동의/미동의 선택이 들어가요. 강조하고 싶은 글자는 **이렇게** 감싸면 굵은 글씨+형광펜으로 보여요. 【 】가 남아 있으면 링크를 만들 때 한 번 더 물어봐요.

📂 계약서 관리

고객이 서명한 계약서를 열람 · PDF로 다운로드 · 삭제할 수 있어요. 삭제하면 구글 시트에서 연락처·서명 이미지·동의 기록이 지워지고 고객 링크도 닫혀요. (예약 카드의 "서명 완료" 표시는 남아요)
